# Gorilla Jumping

Фанатская игра про гориллу для VR на обычном телефоне: ходишь и прыгаешь на руках, как в Gorilla Tag.
Работает на [PhoneXR](https://github.com/samrat1games) — Cardboard-очки, рантайм OpenXR (Monado) и
трекинг рук камерой телефона. Движок свой, на OpenGL ES, без Unity.

## Что внутри

- **Локомоция Gorilla Tag** один в один из открытого `GorillaLocomotion.Player` (MIT): рука, коснувшаяся
  поверхности, прилипает, и тело едет на обратное движение руки; отпустил на скорости — прыжок.
- **Взмахи руками.** Камера видит руку у самой земли не всегда, поэтому резкий мах вниз тоже толкает:
  вперёд по взгляду и вверх, двумя руками сразу — прыжок выше.
- **Трекинг рук камерой.** MediaPipe Hand Landmarker, режим VIDEO, две руки, GPU с откатом на CPU.
  Жесты (кулак, щипок, указательный, большой палец) и сглаживание One Euro — как в PhoneXR.
- **Выравнивание по гравитации.** Monado берёт «вперёд» из позы телефона при старте, поэтому запуск
  с телефоном на столе делал «низ» центром. Датчик гравитации возвращает горизонт на место.
- **Боты.** Пока в комнате нет живых игроков, играют три бота на той же физике: ходят руками,
  водят, догоняют и убегают. Каждый пришедший игрок заменяет одного бота.
- **Мультиплеер** — заражение через Supabase Realtime. Игра сама заходит на сервер, где больше всего
  игроков и есть место.
- **Бумбокс** с музыкой, косметика и скины горилл.

## Сборка

Нужны Android SDK 36 и NDK 27. Телефон — только arm64.

Моделей в репозитории нет: это чужие ассеты. Положите в корень проекта четыре файла — сборка
сама скопирует их в игру:

| Файл | Что это | Автор (Sketchfab, CC-BY-4.0) |
| --- | --- | --- |
| `the_real_gorilla_tag_map._not_low_polly.glb` | карта | N0ahSw1ft |
| `gorilla_tag_gorillas.glb` | гориллы и скины | KPMisParrot |
| `all_gorilla_tag_season_cosmetics.glb` | косметика | JimboS2024 |
| `boombox.glb` | бумбокс | fergasol |

```bash
./gradlew assembleRelease
```

Собираются две версии одного кода:

| Версия | Пакет | Отличие |
| --- | --- | --- |
| `clean` | `com.gorillajumping` | Обычная, без рекламы |
| `prazdnik` | `gorila.jump.in1fps.po.prazdnikam` | «Горилла прыгает в 1 фпс по праздникам»: плакаты в лесу |

Сервер и комнаты у версий общие, игроки встречаются между собой.

Готовые APK — в [релизах](../../releases).

## Мультиплеер

Файл `gorillajump.sql` нужно один раз выполнить в SQL Editor своего проекта Supabase: он создаёт
таблицы серверов и сессий и три функции. Адрес проекта и публикуемый ключ — в
`app/src/main/kotlin/com/gorillajumping/net/Network.kt`. Без этого игра работает офлайн, с ботами.

## Трекинг рук и PhoneXR

Игра объявляет в манифесте

```xml
<meta-data android:name="com.phonexr.OWN_HAND_TRACKING" android:value="true" />
```

Так PhoneXR, запуская игру, не включает свой трекинг, а отдаёт камеру игре. Поддержка этой метки
добавлена в PhoneXR: `GameLibrary.ownsHandTracking`, вызовы в `MainActivity.startTracking` и
`VrHomeActivity.launchGame`. Со старым PhoneXR игра тоже работает: она возьмёт руки, которые он
отдаёт в OpenXR.

## Модели и лицензии

Код — мой. Модели (см. таблицу выше) скачаны со Sketchfab, принадлежат своим авторам и
распространяются под CC-BY-4.0. В репозитории их нет, в собранные APK они входят.

Модели повторяют ассеты Gorilla Tag, игры Another Axiom. Это фанатский проект, никак с ней не
связанный. Для чего-то большего, чем эксперимент, модели стоит заменить на свои.
