Поток данных PhoneXR
====================

Пока в PhoneXR включён трекинг, он 60 раз в секунду шлёт UDP-пакет ASCII-текстом:

  127.0.0.1:42424   рантайму Monado
  127.0.0.1:42425   игре через SDK

Порт занимает один клиент. Если данных нет, их уже читает другое приложение.

Формат (версия PH5, текущая), числа разделены пробелами:

  PH5 <левая рука> <правая рука> <флаги> <pinchL palmL pinchR palmR>

Каждая рука — 14 значений:

  present fist index thumb x y z qx qy qz qw buttons stickX stickY

  present   1, если рука видна камере или подключён Joy-Con этой стороны
  fist      кулак; index — только указательный; thumb — только большой
            (в режиме «только руки» все три всегда 0)
  x y       ладонь в кадре, 0..1; x растёт вправо, y вниз
  z         близость к камере, 0..1 (1 — ближе всего)
  qx qy qz qw  поворот от гироскопа Joy-Con; без гироскопа 0 0 0 1
  buttons   биты кнопок Joy-Con:
              1 A/X, 2 B/Y, 4 курок, 8 хват, 16 меню, 32 нажатие стика, 64 системная

  stickX stickY  стик Joy-Con, -1..1 (x вправо, y вверх)

После флагов — щипок и ладонь к лицу (0/1) для левой и правой руки.

Флаги:

  1  включено отслеживание положения по камере (6DoF)
  2  режим «только руки»: жесты пальцев ничего не нажимают

PH4 — предыдущая версия: 12 значений на руку (без стика), без щипка и ладони.
SDK 1.0.1 читает и PH5, и PH4.

Чтение:

  Kotlin/JVM — com.phonexr.sdk.PhoneXRInput
  C/C++      — runtime/phonexr_input.h
